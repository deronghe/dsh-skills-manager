# 安装、验证与发布

更新时间：2026-09-02（Asia/Shanghai）

## 安装

当前代码版本：[`v0.3.0`](https://github.com/deronghe/dsh-skills-manager/releases/tag/v0.3.0)。npm 上的最新发布为 `0.2.0`，升级版本请按下方「发布新版本」手动执行。推荐直接安装 npm 包，无需下载源码：

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8
dsh plugin --profile web add @deronghe/dsh-skills-manager
```

重启 DSH 后在「设置 → 技能」确认插件界面已更新。若仍显示旧界面，先确认活动 profile 已重新加载该包。若下载镜像尚未同步最新包，可在安装命令末尾添加 `--registry=https://registry.npmjs.org/`。

本地开发或未发布版本可在插件根目录执行 `dsh plugin --profile web add .`。

## 发布新版本

本仓库不依赖 GitHub Actions（发布工作流与本地一键脚本已移除），发布为手动流程：

1. 在插件根目录升级版本号：`npm version patch` / `npm version minor` / `npm version major`。
2. 本地验证：`npm run pack:check` 与 `npm test`。
3. 提交并推送版本号与标签：

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8
git commit -m "chore(release): vX.Y.Z"
git tag -a vX.Y.Z -m "vX.Y.Z"
git push origin main --tags
```

4. 在 GitHub Releases 页基于该标签创建 Release（或执行 `gh release create vX.Y.Z --generate-notes`）。
5. 需要发布到 npm 时，完成 `npm login` 后执行 `npm publish`（包内 `publishConfig.registry` 会强制指向官方 npm registry）。

发布后，重新执行安装命令即可获取指定版本；回滚时安装已验证版本号，例如 `dsh plugin --profile web add @deronghe/dsh-skills-manager@0.2.0`。

## 端到端验收

1. DSH 分组与公共 Agent 分组均可见。
2. 仅 DSH 分组能启用和停用技能；公共 Agent 分组没有修改按钮。
3. 可向 DSH 分组上传 `SKILL.md` 所在目录；同名时需要确认覆盖。
4. 仅 DSH 分组可删除，公共 Agent 分组不出现删除入口。
5. 按 ESC 时只关闭最上层确认框或上传框。
6. 在 DSH Desktop（win32）中，可通过「选择本地文件」上传单个 `SKILL.md`，或通过「选择插件文件夹」打开系统原生目录选择框导入整个插件目录。

## 回滚

从 DSH Web profile 移除当前插件或恢复上一个已验证版本，然后重启 DSH。插件不会修改公共 Agent 目录中的文件结构；DSH 根目录内被覆盖或删除的技能需由安装前备份恢复。
