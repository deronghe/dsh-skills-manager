## 目标与业务边界

给 dsh-skills-manager 补齐三条能力：① 插件自身的 GitHub Releases 版本管理（一键发布脚本 + npm OIDC 工作流 + Release 工作流 + 设置页版本卡）；② 设置面板按「仓库 / 技能 / 关于」页签分门别类，页面更清晰；③ 技能列表支持「推送」——把本地改动一键提交并推送到配置的来源仓库（缺省布局 `skills/<技能名>/`）。

推送语义：统一推送到「仓库」页配置的来源仓库（默认 `deronghe/skills`），不做逐技能来源记忆；公共 Agent 技能目录维持只读。
